# Job Application Portal: project boundaries

- Work only on this job-application-portal application unless the user explicitly names another project.
- Treat every repository as an independent product with its own functions, branding, visual design, and user journeys.
- Do not copy colors, components, layouts, content, or workflows from sibling repositories, KOBIS, or Solarisiot.com. Do not inspect other projects for design references unless the user requests it.
- Keep this portal blue. Its dedicated palette is defined in client/src/styles/PortalIdentity.css; use those tokens for future visual changes.
- Design for this application's actual flow: account creation, applicant profile and resume submission, status tracking, administrator review, and interview scheduling.
- Keep page-specific UX appropriate to each role. Shared styling within this portal does not imply sharing features or designs with other projects.
- Preserve existing local edits. Confirm the repository path and remote before Git operations. Do not push unless the user requests it.

- Preview broad typography changes in the browser before applying them. Preserve a deliberate size hierarchy; do not enlarge all text styles together.
